dsh-thinking-slider · 素材化预览

每一处外观都来自插件**真实渲染出的元素树**（测试替身 React 渲染 → 序列化成 HTML），滑轨 CSS 是插件注入页面的那一份逐字复制；只有官方 MenuSurface 的材质外壳用了一条等价 CSS 还原。这不是运行时截图，是同一份代码的离线渲染，用来在没有 devtools 的 WebView 里核对视觉。

真实位置：DSH Web GUI 输入框右侧 conversation.input.right（order 45）；官方那个 DeepSeek-V4.1-Flash · High 座位是 single 插槽抢不过来，所以插件在运行时给它打标记隐掉，把「选模型」并进这枚 chip 与它的卡片里 —— 下面是接管后的样子（官方座位已不在画面中）。

可以直接拖下面的滑轨：这一页内嵌了一段与被改组件 onInput/onRelease 等价的脚本 —— 拖动时蓝填充与圆钮跟手、跨档时档位名淡入、进最高档时渐变 280ms 淡入并流动、星尘按档位重建、松手吸附到最近的档位、点卡头那行模型名还能把模型清单展开 / 收起（高度 300ms 过渡）。

关键数值

轨道高 26px 满圆角；圆钮 30px > 轨道，所以上下各溢出 —— 素材就是这么画的（49 > 38）
端点内缩15px = 圆钮半径，刻度点因此正好压在原生 range 的圆钮行程上
已填充段`var(--dsw-alias-state-business-primary, #3078f0)`（素材实测 rgb(48,120,240)）
未填充段`color-mix(in srgb, var(--dsw-alias-label-primary, inherit) 14%, transparent)`
刻度点每档一颗、直径 4px；未到达是中性灰，被填充盖住那颗是「品牌蓝 + 白」——两层叠着用 `clip-path` 裁
圆钮30px 白色实心 + 双层投影，hover 放大 1.06、按住 1.16 并带 7px 光晕
步进`step: 0.01` —— **连续**跟手，档位由四舍五入决定（不是一格格跳）
拖动中只写 `--dsh-ts-ratio` 这一个 CSS 变量到滑轨外层，不进 React state；一次拖动只在跨档时重渲染
比例过渡`transition: --dsh-ts-ratio 320ms cubic-bezier(0.34,1.28,0.64,1)`；拖动中临时 `transition: none`
松手**吸附到最近的档位**（`Math.round`，正好在中点时朝强度更高一侧）：草稿值从连续落点换成档位下标，由上面那条 320ms 回弹过渡滑到档位中心 —— 拖动中不吸附（否则一格格跳），只在松手这一刻吸
清单开合卡头模型行点开 ⇄ 收起：外层 reveal 走 grid-template-rows 的 0fr ↔ 1fr（300ms），卡片高度跟着一起长/缩；内层 clip 裁切，清单本体 opacity + translateY(-6px) 淡入下移。清单常驻 DOM —— 收起时若节点直接消失，内容会先在 1 帧内没了、空出来的高度再慢慢收，像被「抽走」；收起态靠 aria-hidden + 每行 tabIndex -1 挡住读屏与 Tab
换档动效档位名重挂 → `dsh-ts-level-in` 200ms 淡入 + 上浮 3px；卡片进场 `dsh-ts-card-in` 180ms
渐变进出非最高档 `opacity: 0` → 最高档 `opacity: 1`，280ms 淡入淡出（不是硬闪）
最高档判定effort ∈ ["xhigh","max","ultra"]（Ultra 额外拿 `data-boost="fast"`）
最高档渐变`linear-gradient(105deg, #0818e0 0%, #4020e8 24%, #a828e8 48%, #c65cf5 62%, #4020e8 82%, #0818e0 100%)` + `background-size: 220% 100%` + `dsh-ts-effort-flow` 6s（Ultra 4s）往复
星尘确定性哈希布点（`starStyleFor`，不用 Math.random），两份星图整体左移 50% 无缝循环；最高档 12 颗、Ultra 22 颗
降级`@media (prefers-reduced-motion: reduce)` 关掉流动、星尘闪烁与所有过渡
禁用态`.dsh-thinking-slider-rail:has(range:disabled) { opacity: .55 }`
接管官方座位官方 `conversation.input.model` 是 **single** 插槽（`dsh-client-ui-slots/lib/index.js:172` 直接抛「already has a registration」）—— 抢不过来，只能在运行时给它的 DOM 打 `data-dsh-thinking-slider-native="hidden"` + CSS `display:none`。判据是「这一排里最后一个带 `aria-haspopup="menu"` 的兄弟节点」，切会话重挂 DOM 时由 `MutationObserver` 重打标记，官方把它锁住（`disabled`）时不接管。
模型清单卡头里那行模型名就是按钮：`modelChoicesOf(snapshot)` 把官方 `groups` / `failures` 铺平（与官方 `optionsOf` 同源、顺序一致），点击即 `directory.select({provider, model, reasoningEffort?})`
换模型带档位`transferEffort`：目标模型声明了同 id 档位就保留（官方 `selectionOf` 是一律回新模型的 `defaultEffort`，这里**有意不同** —— 换 provider 时「高」还是「高」）；没声明就省略该字段，等于用目标模型的默认档
触发 chip`模型名 · 档位`；模型不支持推理等级时只剩模型名 —— 这时它就是一个**纯模型选择器**（所以它不能再像以前那样整段不渲染）
插件注入的 RANGE_CSS（逐字，309 行） 
/* 把「比例」注册成可补间的数值类型：点击轨道 / 键盘跳档 / 返回默认时，
   填充、圆钮、刻度点会一起缓动过去；拖动中由 JS 临时把过渡关掉（跟手优先）。
   —— 「丝滑」就是这两半合起来的手感。 */
@property --dsh-ts-ratio {
  syntax: "<number>";
  inherits: true;
  initial-value: 0;
}
